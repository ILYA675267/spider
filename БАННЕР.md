# Баннер — правила пользователя (с ролика №15, обязательно в каждом ролике)

1. **Где:** строго в середине готового ролика — **начало баннера не дальше ±5 секунд от середины**.
   Склейку выбирать на паузе между предложениями, ближайшей к этому месту; после сборки проверить.
2. **Как появляется:** камера просто меняет ракурс — облёт в той же комнате, без склейки и растворения.
   Отдельная вставка: паучок крупно говорит **«Чуть не забыл!»** — голос пользователя
   `assets/voice/chut_ne_zabyl.mp3` (не озвучивать заново, в текст ролика фразу не писать), рука вверх,
   субтитр сверху.
3. **Баннер:** видео рекламодателя — сейчас **NATRIA VPN** `assets/ads/natria_vpn.mp4` (7,2 с).
   Зелёный фон убирается. По центру экрана, **не меньше 25% экрана**: ширина 1134 px — чуть шире кадра,
   края баннера на 27 px уходят за экран (только скруглённые уголки).
4. **Звук баннера** — из его файла, не убирать и не приглушать; **громче исходника в 2 раза (+6 дБ)**.
   Звук ролика на это время молчит.
5. **Ролик под баннером НЕ идёт.** Паучок под баннером спокойно жестикулирует руками и чуть качает головой.
6. **После баннера** — облёт камеры обратно в прежний ракурс, ролик продолжается с того же места.
7. **Длина:** вставка добавляет ≈ 9 с, поэтому речь ролика ≈ до 43 с + концовка, итог ≤ 1 минуты.

## Как вставлять
После рендера ролика:
```
python tools/ad_banner.py insert output/<тема>.mp4 <секунда паузы, камера стоит> output/<тема>_ad.mp4 <модуль_ролика>
```
(~10 мин), затем версия для телефона. Новый баннер — прислать видео на зелёном фоне и заменить файл в `assets/ads/`.
