# 3D-ролики с чиби-пауком (Reels / Shorts 9:16)

Отвечай по-русски, просто, без терминов. Пользователь присылает тему → делаем короткий вертикальный
ролик, где 3D-персонаж рассказывает историю: жестикулирует, показывает рукой, двигает головой,
нижняя челюсть маски двигается в такт речи (рта не видно — он под маской).
Главное требование пользователя: персонаж ведёт себя как живой человек, а не кукла.

## ОБЯЗАТЕЛЬНО в каждом ролике (правила пользователя)
Канал: интересные факты о жизни, взрослой жизни, иногда о нейросетях. Паучок — только рассказчик
(ролики не про супергероев). Telegram-канал проекта: «Паучья Норка» — https://t.me/pit_of_spider, аватар — `output/avatar.png`.
1. **Начало**: вопрос-крючок (как в INSTA) → фраза **«Паучок объясняет»** (фирменная заставка) → объяснение.
2. **Концовка**: призыв в Telegram «Паучья Норка» (там интересное и эксклюзив). Голос концовки — шаблон
   `assets/voice/outro_telegram.mp3` (не озвучивать заново). В кадре — скриншот канала `assets/tg_channel.png`
   и оригинальные значки Telegram `assets/logos/telegram.png` — **значок всегда круглый**.
   Дизайн (по просьбе пользователя — как в INSTA, но тёмный): стеклянная тёмная карточка канала
   (круглая аватарка в голубом ободке + круглый значок Telegram, «Паучья Норка», «Telegram-канал · t.me/pit_of_spider»),
   карточка крупная, по центру, лицом к зрителю, опускается сверху; на кнопке маленькая паутинка;
   голубое и тёплое свечение сзади, отдельная объёмная кнопка-пилюля «Подписаться» со значком, 3D-палец
   (`assets/finger_3d.png`) подъезжает и нажимает → «Ты в норке!», штамп «ЭКСКЛЮЗИВ», медленный наезд камеры.
   Код — `memory_mg.py`, сцена 8 (`tg_glass_card`, `tg_pill`, `glow_behind`).
3. **Стиль**: динамичный моушн-дизайн, объём, **тёмные цвета** в тон фону и персонажу.
4. **Персонаж небольшой** в кадре — главное информация.  5. **Длина** до 1 минуты.
6. **Челюсть маски** двигается в такт голосу, заметно (`jaw` растяжение 0.2).
7a. **Все вставки со скруглёнными углами** (карточки, кнопки, бортики; столбики — со скруглёнными рёбрами):
   `mg.panel(radius=...)`, `mg.box(radius=...)` — по умолчанию уже скругляют.
7b. **Вставки никогда не закрывают персонажа** — перед рендером `python tools/check_occlusion.py` (должно быть []).
7d. **Полоски на полу — только в одну сторону** (`floor_grid(..., axes=(0,))`), без перекрёстных — не «катаются».
7e. Никаких прямых бликов/линий поверх скруглённых кнопок (на кнопке «Подписаться» блик убран — резал глаза).
7c. **Фон по кругу без швов** — `Room` зеркалит картинку на стыках (не убирать).
7. **Чёткая картинка**: без зерна, без лишнего размытия (размытие только на долю секунды резкого облёта).
8. **Стикеры пока НЕ используем** (пользователь отложил).
9. **Текст для озвучки** — части до 500 символов, считая русскую букву за 2 (≈ до 240 букв на часть),
   резать только между предложениями. Пользователь озвучивает в Fish Audio и присылает файлы;
   Claude может резать/склеивать/чистить звук (паузы, смех, лишние фразы), интонацию — только перегенерацией.
   Чистка пауз — только по громкости звука с удержанием 0,25 с после слова (НЕ по отметкам распознавания:
   они ставят конец слова раньше, и окончания срезаются). После чистки проверять: речь не ослаблена (0 дБ).
11. **Рекламный баннер в середине ролика** (с ролика №15): между двумя сценами в середине — **камера просто меняет ракурс**
   (облёт в той же комнате, без склейки/растворения) к **отдельной вставке**: паучок крупно говорит **«Чуть не забыл!»** (голос пользователя
   `assets/voice/chut_ne_zabyl.mp3`, не озвучивать заново; рука вверх, субтитр сверху), затем по центру экрана —
   баннер (сейчас `assets/ads/natria_vpn.mp4`, 7,2 с, зелёный фон убирается, **не меньше 25% экрана**: ширина 1134 px — чуть шире кадра, края баннера на 27 px уходят за экран; **звук баннера — из его файла, не убирать и не приглушать; громче исходника в 2 раза (+6 дБ)**), а паучок под баннером
   **спокойно жестикулирует руками и чуть качает головой**. Ролик под баннером НЕ идёт; после — облёт камеры
   обратно в прежний ракурс, ролик продолжается с того же места. В текст ролика фразу не писать — она в шаблоне.
   После рендера: `python tools/ad_banner.py insert output/<тема>.mp4 <секунда паузы, камера стоит> output/<тема>_ad.mp4 <модуль_ролика>`
   (~10 мин) → версия для телефона. Вставка добавляет ≈ 8,5 с: речь ролика ≈ до 43 с + концовка, итог ≤ 1 минуты.
10. Работать по шагам: когда пользователь «вносит правки» — только запоминать, ничего не собирать.

## Описание к ролику (шаблон из INSTA — для КАЖДОГО ролика, присылать вместе с видео)
Три строки, без пунктов и призывов, без фразы «создано с помощью ИИ»:
```
<суть видео кратко>
TELEGRAM: Паучья Норка
<РОВНО 5 хэштегов: 3 про канал (#интересныефакты #фактыожизни #паучокобъясняет) + 2 по теме ролика>
```

## Как делается ролик
1. Сценарий (≤ 1 мин) → части до 500 знаков → пользователь присылает mp3 частей.
2. Распознать каждую часть с временем слов (faster-whisper small, `asr.py`-подобный скрипт), почистить,
   склеить с паузами 0.32 с + шаблон концовки → `work/<тема>/voice_full.wav`, `words.json`.
3. Скрипт ролика по образцу `tools/memory_mg.py`: SUBS (фразы + выделения), CAMERA/OFFSET (сцены, облёты expo),
   SEC (угол сцены для вставок), ARM_L/ARM_R/HEAD/JUMPS (жесты), items_for (вставки), SFX.
   `--preview` — 22 кадра за 30 с для проверки (субтитры влезают, вставки не режутся краем, не закрывают персонажа).
4. Полный рендер — параллельно на 4 ядрах (`--jobs 4`, как в `tools/money_mg.py`): ~25 мин на 50 с видео → `output/<тема>.mp4`.
   Пока идёт рендер — ничего тяжёлого не запускать.
   Монтаж НЕ делать однотипным: в каждом ролике менять приёмы камеры (кран сверху, dolly zoom, наклон кадра, съёмка снизу,
   медленный облёт), сторону персонажа (слева/справа), цвет сцен и типы вставок (ролик №3 — `tools/money_mg.py`).
   В шрифтах нет «₽» — рисовать через `text_rub()` из `money_mg.py`.
5. Для пользователя всегда делать **совместимую версию для телефона** (галерея!):
   `ffmpeg -i <тема>.mp4 -c:v libx264 -profile:v main -level:v 4.1 -preset slow -crf 21 -bf 0 -g 60 -pix_fmt yuv420p
   -r 30 -c:a aac -b:a 160k -ar 48000 -ac 2 -movflags +faststart <имя_латиницей>.mp4` (≈22 МБ, влезает в чат) — её и отправлять.

## Текущий способ (выбран пользователем): 2.5D моушн-графика на Python, бесплатно
- `tools/mg.py` — движок: камера с облётом/наездами/«ручной» тряской, круглая комната
  (`Room`: стена — зацикленная картинка `assets/bg_grid.jpg` на цилиндре, сплошной пол; стык точный),
  сетка пола, объёмные карточки `panel`, 3D-столбики/здания `box`, тени `floor_blob`,
  персонаж-«кукла» `Puppet` из рисунка `assets/char_tpose.jpg` (руки, тело, голова, челюсть маски).
- `tools/intro_mg.py` — тест 10 с (сценарий: CAMERA, OFFSET, ARM_L/ARM_R, HEAD, SUBS, вставки).
  `python tools/intro_mg.py work/intro/voice.wav output/intro_mg.mp4 [--preview]` (~6 мин; --preview — 10 кадров за 20 с).
  Нужны: numpy, pillow, opencv-python-headless; ffmpeg.
- Пользователь проверяет стык стены и пола — следить, чтобы стена не просвечивала сквозь пол.
- Голос пока временный (Piper); итоговый — Fish Audio (пользователь присылает файл или API, см. SETUP_API.md).

## Как устроено (архив, 3D в Blender)
- `tools/character.py` — персонаж собирается в Blender из простых форм (голова-шар, глаза-линзы,
  паутина рисуется материалом, чёрный мультяшный контур). Скелет — иерархия шарниров (`P[...]`).
- `tools/poses.py` — позы рук (`ARM`), кистей (`HAND`), `pose(left, right, head=, spine=, legs=)`;
  `Animator`: `pose(t, ...)`, `talk()` (челюсть + кивки), `blink()`, `eyes()` (прищур/удивление),
  `life()` (голова и корпус никогда не замирают, перенос веса), `breathe()`.
  Голова начинает движение раньше руки, локоть/кисть/пальцы догоняют (LAG) — это и даёт «живость».
- `tools/scene.py` — камера 9:16, свет, тень; фон прозрачный.
- `tools/background.py` — фон по умолчанию (крыша на закате) → `assets/background.png`.
  Пользователь может заменить фон своей картинкой 1080×1920.
- `tools/probe.py` — проба: 10 с жестов без голоса (функция `choreography`).
- `tools/compose.py` — кадры + фон (+ звук) → mp4 1080×1920.

## Запуск
Blender ставится как модуль Python: `python3 -m venv bv && bv/bin/pip install bpy pillow`
(видеокарты нет; для быстрого движка Eevee её не хватает — рендерим Cycles на процессоре).
```
bv/bin/python tools/probe.py -- work/probe/frames 720 1280 10   # ~8 с/кадр, 10 с видео ≈ 35 мин
bv/bin/python tools/probe.py -- /tmp/prev 360 640 0             # черновик за 1,5 мин (без света/паутины)
python3 tools/compose.py work/probe/frames assets/background.png output/probe.mp4
```

Тема: **«Почему ожидание отпуска радует больше самого отпуска»** — предвкушение поездки поднимает настроение
